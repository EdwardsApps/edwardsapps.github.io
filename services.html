Custom builds

Software for firms like yours, from someone who's run one.

Internal tools, job trackers and integrations for trades, contractors and charities — designed and built by Peter Edwards, who has run a surfacing firm, chaired a charity and kept a pub for nine years.

How it works

A conversation, not a ticket queue.

You describe how the work actually runs — who does what, where it lives now, what goes wrong on a bad week. Peter builds the tool that fits it, shows you working software early, and adjusts it against real use. You deal with the same person from first email to finished tool, and that person has stood where you're standing.

What gets built

The tools small firms actually need.

  • Internal tools that replace the spreadsheet everyone's afraid to touch.
  • Job trackers and scheduling tools shaped around how your crews really work.
  • Integrations that stop the re-keying — Sage, Xero, WhatsApp.
  • Apps delivered properly, including through the Apple App Store.

Why it works

Built by the person who'd have to use it.

Most custom software fails at the same point: the people building it have never done the job it's for. Peter has run the schedule, chased the invoices, kept the charity's books straight and cashed up the till. The products on this site — CrewBook, OurSpace, Almoner — all started as tools he built because he needed them. Yours would be built the same way.
