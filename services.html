Why it works

Built close to the work.

↗

Custom software tends to come unstuck when the people building it have never done the job it is for. Peter has run the schedule, chased the invoices, kept the charity's books straight and cashed up the till. The products on this site — CrewBook, Studiobooks, OurSpace, Almoner — all started as tools he built because he needed them, and yours would be built the same way.

Start with an email.

A few plain words about what's slow, what's on paper and what gets lost is enough to begin with. Peter reads every email himself, and he'll say if he doesn't think it's worth building.
